P1

開場：個案背景與歷史

約 1.5 分鐘｜披薩成功了幾十年，其他當日配送卻大多失敗
虹均
當日配送不是新點子：以前試過，除了披薩幾乎都失敗；2012 年又有一批大公司重新投入。

// 要講的內容

  • 美國的披薩外送已經成功幾十年，但其他當日配送大多失敗
  • Urbanfetch：在倫敦、曼哈頓、布魯克林等人口密集區營運，2000 年秋天因為資金不足倒閉
  • Kozmo：募資超過 2.8 億美元、在 11 個城市營運，2001 年初倒閉
  • 2012 年左右戰火重燃：Amazon、Walmart、eBay 大舉投入，Instacart 等新玩家也加入

// 講稿參考 大家應該都叫過披薩外送，在美國它已經成功好幾十年了。可是除了披薩，其他當日配送幾乎都失敗。像 1990 年代末網路泡沫的時候，Urbanfetch 在倫敦和紐約做，2000 年就因為沒錢倒了；Kozmo 募了超過 2.8 億美元、開了 11 個城市，2001 年也收掉了。結果到 2012 年左右，Amazon、Walmart、eBay 又重新開打，還多了 Instacart 這種新玩家。
「那這一次的新玩家是怎麼做的？先從最大的兩家零售商 Amazon 和 Walmart 開始，交給祥卉。」
P2

Amazon 與 Walmart

約 2 分鐘｜兩大零售巨頭，走了不一樣的路
祥卉
Amazon 全力衝「送到家」，規模很大但獲利不明；Walmart 試過送到家之後，轉向「門市取貨」。

// 要講的內容

  • Amazon：2017 年宣稱在超過 5,000 個城市，為 Prime 會員提供上百萬品項的當日到貨（訂單需滿 $35）
  • 不清楚這樣做有沒有賺錢；有評論認為，只要成本壓得夠低，就會重創實體零售
  • Walmart：2012 年回應 Amazon，在北維吉尼亞、費城、明尼亞波利斯、聖荷西、舊金山試辦當日配送
  • 到 2017 年改成主打「門市免費當日取貨＋免費兩日到貨」

// 講稿參考 先看 Amazon。到 2017 年，它說在超過 5,000 個城市，Prime 會員訂單滿 35 美元，就有上百萬種商品可以當天送到。但它到底有沒有賺錢，外界其實不清楚。有人認為，如果 Amazon 真的能把成本壓低，實體零售店會很慘。Walmart 在 2012 年跟進，在舊金山、費城等幾個城市試辦，可是到了 2017 年，它的重點變成「到門市免費當天取貨」，再加上免費兩天到貨。
「這兩家都是賣自己的庫存。接下來兩家不太一樣，商品不一定是自己的，交給佳貞。」
P3

eBay 與 Instacart

約 2 分鐘｜不靠自有庫存的兩種模式
佳貞
eBay 的「代買代送」做了幾年就收掉；Instacart 用平台跟零售商合作，擴張很快，但很晚才開始賺錢。

// 要講的內容

  • eBay：配送的商品不一定是自己的庫存，例如派快遞員到 Macy's 買，再在一小時內送到顧客手上
  • 在舊金山有 50 名快遞員；2015 年關掉 eBay Now，代表這門生意大概很難獲利
  • Instacart：總部在舊金山，估值超過 30 億美元，由員工替顧客採買生鮮再送到家
  • 涵蓋美國大部分主要城市，和 Whole Foods、Costco 等百多家零售商合作，幫它們在配送上對抗 Amazon
  • 成長很快，但到 2017 年才開始獲利

// 講稿參考 eBay 的做法很特別：它送的東西不一定是自己倉庫裡的。《華爾街日報》報導過，有顧客下單之後，eBay 派快遞員去 Macy's 買，一小時內就送到。它在舊金山有 50 個快遞員，但 2015 年就把 eBay Now 收掉了，看起來很難賺錢。Instacart 則是請員工幫你去超市買菜再送到家，跟 Whole Foods、Costco 等一百多家零售商合作，估值超過 30 億美元。它長得很快，不過到 2017 年才第一次賺錢。

國際案例：澳洲與日本

約 1.5 分鐘｜限定區域、特定客群的做法
筱于
在美國以外，也有把範圍或客群縮小的當日配送，而且反應不錯。

// 要講的內容

  • The Iconic（澳洲，賣服飾、鞋子、配件）：雪梨市區 3 小時內完成揀貨、包裝、送達，運費 $9.95
  • 只在營業日早上 7 點到晚上 6 點；公司雖然年輕，這項服務很受歡迎
  • Seven-Eleven Japan 的 7-Meal：鎖定日本高齡人口，提供高品質餐點
  • 顧客可以到 7-Eleven 門市取餐，也可以送到家裡或辦公室
